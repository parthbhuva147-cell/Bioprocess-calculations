# BioProcess Calc

Browser-based bioprocess calculation tools for research and process-development workflows.

## Current functions

- Specific growth rate (mu)
- Doubling time
- Biomass yield Yx/s
- Product yield Yp/s
- Volumetric productivity
- Carbon input from glucose
- Carbon output associated with CO2 volume
- CSV cultivation analysis
- Process trend visualization
- Summary CSV export

## CSV format

Use:

time,biomass,substrate,product

Recommended units:
- time: h
- biomass: g/L
- substrate: g/L
- product: g/L

## Scientific scope

The current version performs simplified interval calculations and is intended for exploratory analysis.
Users should verify assumptions and units before formal or regulated use.
