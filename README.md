# BioProcess Calc — Simple Version

This version intentionally contains only eight stand-alone calculators:

1. Growth rate and doubling time
2. Biomass yield Yx/s
3. Product yield Yp/s
4. Substrate consumption efficiency
5. Volumetric product productivity
6. Biomass productivity
7. Carbon from glucose
8. Carbon from CO2 volume

Removed: file upload, CSV/Excel parsing, multi-file analysis, plots, process-time settings, column mapping, dashboards, carbon ledger, HPLC/OD/DCW integration, and advanced signal processing.

## Publish on GitHub Pages

Replace the existing repository files with:
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

If GitHub Pages is already enabled, no additional Pages configuration is required.
