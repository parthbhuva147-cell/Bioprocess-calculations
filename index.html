DATA GUIDE

Why a bioreactor file and a sampling file are different

01

Online process data

Bioreactor exports usually contain DO, pH, temperature, stirring, gases, feed and off-gas signals.

02

Offline measurements

OD, DCW, residual glucose and HPLC product concentrations are normally measured only at sampling points.

03

Process analysis

This analyzer can inspect the continuous reactor file directly and visualize its native process signals.

04

Yield calculations

Yx/s and Yp/s require biomass/substrate/product data; these can later be synchronized with reactor timestamps.
